Rebuild Chainstate Advanced
If the Bitcoin log reports a corrupted or damaged chainstate (coins) database, rebuild it from the blocks already on the drive. This takes many hours, and most of MyNode is unavailable until it finishes.

If the Bitcoin log reports that a block can't be read from disk, an I/O error, or damaged block files, run a full reindex. Bitcoin re-reads every block file and downloads damaged blocks again from peers.
This is slower than rebuilding the chainstate and can take a day or more. Most of MyNode is unavailable until it finishes.

Custom Bitcoin Version Advanced
To install a specific fork or patched version of Bitcoin, you can select an option from the list. Installing a new version may take a long time and will reboot the device. To undo a previous change, select Default.
Using a custom version may break other features and applications or require configuration changes to work properly. Only install versions you trust and are familiar with as misunderstandings or chain-splits could lead to lost funds.
Custom Bitcoin versions with a specific version will stick to that version and versions listed with (autoupdate) will automatically update to new versions. The default option will also always auto-update. Updates only occur upon installing a new version of MyNode.
